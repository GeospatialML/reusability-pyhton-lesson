# Reusability and reproducibility of Geospatial Machine Learning workflows

This lesson focuses on how to document the creative process behind each model, which represents a good starting point for a set of guidelines to promote FAIR standards within the geospatial ML modeling community.
Data versioning will be addressed using tools such as Data Versioning Control (https://dvc.org/), as proper data management is crucial.
